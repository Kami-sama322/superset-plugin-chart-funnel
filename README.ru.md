# 🪣 Funnel Chart Plugin — чарт-плагин Apache Superset
---

### 🇷🇺 Русский | [🇬🇧 English](README.md)

---

> **Кастомный плагин Apache Superset**: воронка в стиле PowerBI Funnel —
> последовательные этапы, проценты конверсии, цвета по шагам,
> кастомизируемые тултипы и cross-filtering на дашборде. Подготовка
> датасета не требуется — плагин сам делает группировку и агрегации.

---

## ✨ Возможности

- Чарт для дашборда (**не** Native Filter)
- **Два режима данных**:
  - *Значения измерения* — выберите измерение и метрику; плагин сам
    выполняет `GROUP BY`, каждое значение измерения становится шагом воронки
  - *Поля как шаги* — вставьте несколько колонок; каждая колонка становится
    шагом, **порядок шагов соответствует порядку вставленных полей**,
    метрика агрегируется по строкам, где колонка заполнена
- **Доли**: процент от первого шага и процент от предыдущего шага —
  на лейблах, в колонке конверсии и в тултипах. «Первый шаг» — всегда
  самая широкая часть фигуры (у пирамиды — основание, поэтому конверсии ≤100%)
- **Содержимое лейблов** как в PowerBI: значение / % от первого /
  % от предыдущего / комбинации
- **Две формы**: *Прямоугольники* (отдельные полосы по центру, вид PowerBI)
  и *Воронка* (сплошные трапеции)
- **Две дополнительные формы**: *Воронка (плавная)* — криволинейные переходы
  на монотонном кубическом сплайне, без острых скачков, и *Пирамида* —
  треугольник с полосами равной высоты (минимальное значение у вершины,
  максимальное у основания)
- **Сортировка ASC/DESC для всех форм**: DESC зеркалит пирамиду
  (основание сверху, вершина снизу)
- **Высота полос**: относительная в процентах (100% — весь экран) или авто
  (заполнить доступную высоту)
- **Цвета**: градиент по sequential-схеме или свой цвет для каждого шага
- **Тултипы**: выбор дополнительных колонок и/или Handlebars-шаблон
- **Cross-filtering**: клик по шагу фильтрует дашборд — `IN` по значению
  измерения (режим измерения) или `IS NOT NULL` по колонке шага (режим
  полей); мультивыбор с переключением
- Сортировка (по значению / по алфавиту, asc / desc) в режиме измерения
- D3-форматы чисел и процентов, слайдер зазора, отключение лейблов

## 🚀 Установка

### Шаг 1. Клонируйте репозиторий Superset (нужной версии)

```bash
git clone https://github.com/apache/superset.git -b 6.1.0;
```

### Шаг 2. Клонируйте репозиторий плагина

```bash
git clone https://github.com/Kami-sama322/superset-plugin-chart-funnel.git;
```

### Шаг 3. Запустите скрипт автоустановки

```bash
chmod +x superset-plugin-chart-funnel/install.sh;
./superset-plugin-chart-funnel/install.sh ./superset;
```

> `./superset` — корень репозитория Superset из шага 1. Скрипт устанавливает
> плагин как **самостоятельный npm-пакет** в
> `superset-frontend/plugins/plugin-chart-funnel/` и регистрирует его
> в документированных точках расширения Superset. npm workspaces
> (`plugins/*`) линкует пакет при следующем `npm install`.

#### Что делает скрипт:

| Действие | Файл |
|----------|------|
| 0. Устанавливает пакет плагина | `superset-frontend/plugins/plugin-chart-funnel/` |
| 1. Регистрирует плагин в extension hook | `superset-frontend/src/setup/setupPluginsExtra.ts` (`key: chart_funnel`) |
| 2. Добавляет `file:`-зависимость workspace | `superset-frontend/package.json` |

> Path alias `@superset-ui/plugin-chart-*` уже покрывает пакет — отдельная
> запись в `tsconfig.json` не нужна. `FILTER_SUPPORTED_TYPES` **не**
> изменяется (это chart, а не Native Filter).

### Шаг 4. Сборка и запуск

```bash
cd superset/superset-frontend
npm install
npm run dev-server
```

Production-сборки работают так же — см. соседний репозиторий
`superset-prod-dockerfile/`.

## 🧭 Использование

1. **Charts → + Chart → Funnel**, выберите датасет.
2. Выберите **режим данных (Data mode)**:
   - *Dimension values*: выберите **Измерение** (например, стадию продажи)
     и **Метрику** (например, количество сделок). Шаги упорядочиваются
     по метрике (по убыванию по умолчанию, сортировка настраивается).
   - *Fields as steps*: перетащите колонки в **Step fields** в том порядке,
     в котором должна идти воронка. Значение шага = агрегат метрики по
     строкам, где колонка заполнена. Метрика по умолчанию — `COUNT(*)`.
3. Настройте цвета, форму, лейблы и тултип в секциях **Display** и
   **Tooltip**.
4. Чтобы клик по шагу фильтровал дашборд, включите **cross-filtering**
   на чарте и на дашборде.

### Переменные шаблона тултипа

Встроенные: `{{label}}`, `{{value}}`, `{{value_formatted}}`,
`{{percent_first}}`, `{{percent_first_formatted}}`,
`{{percent_previous}}`, `{{percent_previous_formatted}}`.
Колонки из **Tooltip contents** доступны по своим именам (режим измерения).

## ⚙️ Справочник настроек

### Query

| Контрол | Режимы | Описание |
|---------|--------|----------|
| Data mode | оба | `dimension` (группировка) или `fields` (колонки как шаги) |
| Dimension | dimension | Колонка со значениями шагов |
| Step fields | fields | Колонки, по одной на шаг; порядок важен |
| Metric | оба | Агрегация; пусто → `COUNT(*)` |
| Row limit | dimension | Максимум 50 шагов по умолчанию |

### Display

| Контрол | Описание |
|---------|----------|
| Shape | Прямоугольники (PowerBI) / Воронка / Воронка (плавная) / Пирамида |
| Color mode | Градиент / Свой цвет для каждого шага |
| Gradient color scheme | Sequential-схема (режим градиента) |
| Step colors | Готовый список шагов с пипетками (из результата запроса / из полей); шаги без цвета — из categorical-схемы |
| Show labels + Label content | Видимость лейблов и их содержимое: Значение / % от первого / % от предыдущего / комбинации |
| Conversion column | Галочка + селектор содержимого: Значение / % от предыдущего / % от первого |
| Bar height, % | 100% — полосы заполняют экран (по умолчанию), меньше — тоньше; Gap — физический зазор между полосами |
| Number format / Percent format | Стандартные D3-форматы Superset |
